## Publicação de código no GitHub

- Versione e envie ao GitHub todo código criado ou alterado para o projeto, inclusive consultas, scripts temporários, notebooks e utilitários pequenos. Antes de encerrar a tarefa, leve o código avulso para uma pasta permanente do repositório. Para tarefas pessoais sem projeto associado, use o repositório pessoal de scripts avulsos.
- Comente no próprio código sua finalidade e as decisões, pressupostos ou efeitos que precisam de explicação. Documente no README ou índice do projeto o que o código faz, como executá-lo, quais entradas e dependências requer e quais saídas ou alterações produz.
- Use o repositório autorizado e respeite sua visibilidade. Para edições públicas, substitua credenciais, identificadores privados, dados pessoais e detalhes internos de produção por parâmetros, variáveis de ambiente ou exemplos fictícios. Preserve os originais locais e os direitos sobre dependências e material de terceiros.
- Verifique os arquivos que serão enviados, faça o commit e o push e confirme os arquivos e a revisão no GitHub. Se algo impedir a publicação, registre o arquivo pendente e o motivo.
